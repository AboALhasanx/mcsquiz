Avatar assets in this folder
============================

The avatar set is 12 animal faces only — no human figures, chosen so the picker
stays neutral for a conservative audience.

Source: Twemoji (jdecked/twemoji, the community-maintained Twemoji fork)
  https://github.com/jdecked/twemoji
  Graphics licensed under CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
  (the code in that project is MIT; these files are the graphic assets)
