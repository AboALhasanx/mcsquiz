Avatar assets in this folder
============================

Twenty-five round cartoon portraits, cut out of the vector sheet supplied by
the account holder (210800663238.zip -> avatars_round_25_color.eps):

    person-01.png ... person-25.png

Each file is a 128x128 PNG: the coloured disc of the original artwork, with
the white sheet behind it removed, so the corners are transparent and the
picture can sit directly in a round avatar slot. The colours are quantised
to keep every file around 15 KB.

Source: Freepik (https://www.freepik.com) — "Avatars round 25 color". The
art is used as supplied by the account holder; the credit is kept here so the
origin stays traceable.

Re-cutting the set from the original file:

    python tools/extract_round_avatars.py "<path to avatars_round_25_color.eps>"

The tool rasterises the EPS once (Ghostscript -> one cropped page PDF ->
PyMuPDF), finds the 25 discs by connected-component analysis, then crops and
masks each one.

Earlier sets (the hand-drawn profile icons, Twemoji animals and an in-house
drawn animal set) were removed: the round cartoon set is the one to keep.
